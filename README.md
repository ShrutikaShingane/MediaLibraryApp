# Media Library Console Application

## Project Overview

A Java console-based application that manages songs and videos using a common `Playable` interface.

## Features

* Add songs and videos
* Display all media items
* Play a selected media item
* Use Java interfaces and polymorphism
* Handle invalid menu choices and media selections

## Technologies Used

* Java
* Eclipse IDE
* Object-Oriented Programming (OOP)

## Project Structure

```text
src/
└── medialibrary/
    ├── Playable.java
    ├── Song.java
    ├── Video.java
    └── MediaLibraryApp.java
```

## How to Run

1. Import or open the project in Eclipse.
2. Open `MediaLibraryApp.java`.
3. Run it as a Java Application.
4. Use the console menu to add, list, and play media items.
